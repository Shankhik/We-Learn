# Version 1.0.0

## Clean UI

This version comes with a fresh look which the users will definitely like. Removed the accent colors; now the UI color is mostly the same with some color variants in certain components in certain pages.

UI components visual consistency is heavily improved from the previous version and other visual inconsistencies will be fixed on the later updates if found.

## Better Performance

**<u>Memory Usage</u>** of the app has been optimized significantly by:
* using garbage collectable code.
* removing memory leaks in code.

**<u>Caching</u>**  is used for getting faster data fetching making the app fast in delivering content for user. Users will definitely feel the difference.

## Improved Security

Overall security of the app has been improved; though the users may not notice them.
The app is totally secure against:
* XSS (Cross Site Scripting) attack
* CSRF (Cross item Request Forgery) attack

The app's security is constantly being worked on.
